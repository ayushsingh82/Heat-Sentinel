# FortyGuard Hackathon'26 — Submit

Source: https://www.fortyguard.com/hackathon26

## Process

1. **Register** — Create your team (solo or up to 3, no climate background required) and secure your spot.
2. **Build** — Develop your solution during the 2-week sprint (Aug 18 – Aug 30) using FortyGuard's Temperature API.
3. **Submit** — Present your project before the deadline (Aug 30, 23:59 GST).
4. **Win** — Compete for prizes, recognition, and career opportunities.

## What every participant gets

- Free Temperature API access
- Trial API credits
- Developer quickstart
- Documentation
- Community Slack
- Technical support
- Certificate of completion
- Partner network access

## Prize pool — $6,000

- 1st place — $3,000 cash + internship pathway + partner promotion
- 2nd place — $2,000
- 3rd place — $1,000
- Plus: NVIDIA Jetson AI Developer Kit for each winning team (67 TOPS, 1,024 CUDA + 32 Tensor cores, 6-core ARM CPU, 8GB LPDDR5)
