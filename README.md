# fortyguard-agent

AI agent built for the [FortyGuard Hackathon'26](https://www.fortyguard.com/hackathon26) — "Building the World's Temperature AI."

Hackathon details (timeline, submission process, rules) are in [`hackathon/`](./hackathon).

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
